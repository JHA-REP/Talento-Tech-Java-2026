# Proyecto TechLab - Talento Tech Java 2026

Sistema de gestión de productos y pedidos desarrollado en Java.

## Características
- Gestión de Productos: Alta, listado, actualización y control de stock.
- Gestión de Pedidos: Creación de pedidos con líneas de producto y cálculo de totales.
- Validaciones y Excepciones Personalizadas: Control de stock insuficiente, datos inválidos y entidades no encontradas.
- Interfaz por Consola: Menú interactivo para el usuario.

## Estructura del Proyecto

src/com/techlab/
  excepciones/   # Excepciones de negocio personalizadas
  pedidos/       # Entidades y servicios de pedidos
  principal/     # Clase principal, consola y menús
  productos/     # Entidades y servicios de productos
